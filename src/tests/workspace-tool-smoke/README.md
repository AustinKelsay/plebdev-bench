# Workspace Tool Smoke

Minimal workspace preflight for read/write tool harnesses.
The parent directory for the created report is preseeded so this stays a pure read/write task.

## Task

- read one seeded file
- update one existing file
- create one small report file

## Pass Criteria

- `checklist/steps.txt` matches the exact final contents
- `reports/status.txt` exists with the exact final contents
- no other files are changed
