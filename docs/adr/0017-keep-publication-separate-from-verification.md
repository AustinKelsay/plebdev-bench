# Keep publication separate from verification

Plebdev Bench allows a redacted local **Run Result** and **Run Plan** to become a **Published Run** without requiring independent verification. Requiring verification before publication would create a stronger trust boundary, but the project is local-first and currently operator-controlled; publication should mean shared for analysis, while **Run Provenance** records whether the run is self-reported, verified, rejected, and eventually supported by **Tamper Evidence**.
